# Loop v0.2.20

- 处理流改为紧凑树形展示：标题下方直接显示结论，移除节点尾部操作按钮、状态文字和子节点数量。父子关系、折叠与拖动调整层级保持可用。
- 点击节点前的图标，直接按「未完成 → 已完成 → 待确认」切换；支持筛选待确认节点并保留父级上下文。
- 右键节点添加结论、子节点或同级节点；双击标题或结论直接编辑，不再打开节点记录浮窗。原记录内容保留并合并显示在结论中。
- 修复双击标题后编辑区域空白、结论编辑区高度不足的问题。输入框沿用项目中性细线样式，支持明暗主题。
- 已完成节点的标题和结论各默认省略为一行；鼠标悬停展开，单击可保持展开。
- 首次成功新建节点后，在底部提示可通过右键添加结论；提示只出现一次。
