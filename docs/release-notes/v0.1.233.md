# v0.1.233

## 知识笔记 Markdown 编辑升级

- 提供 Markdown 源码、实时预览和阅读三种模式，切换时保留正文、编辑历史和选区。
- 支持标题、嵌套列表、任务列表、表格、代码高亮、脚注、高亮、公式、Mermaid、Callout、注释和 YAML frontmatter。
- 增加当前笔记查找替换、格式快捷键、折叠、表格行列编辑、图片粘贴和拖入，以及上传失败重试。
- 增加笔记快速切换、大纲、内部链接补全、反向链接、缺失目标创建和基础段落块引用与嵌入；重命名通过稳定标识和历史名称保持关联。
- 修复自动保存和手动保存的竞态、切换笔记时的异步串写，以及保存后重复提示外部修改的问题。保存失败保留草稿，外部修改冲突需明确处理。
- 继续使用现有任务归属、本机数据目录、Markdown 文件绑定、附件和恢复机制；历史正文按原文读取，不做覆盖式格式迁移。

## 使用与兼容

- 原有知识笔记入口保留，处理流短记录继续使用原有编辑器。
- 基础块引用支持段落 `^id`，笔记嵌入最多三层并检测循环。
- 本版本不增加云同步、插件系统或知识图谱。
- 修复部分时区下回顾页日期范围标签少显示一天的问题。

## 验证

- 发布前本地检查：主项目 323 项测试、反馈服务 11 项测试通过。
- Chromium 实际界面验证覆盖模式切换、输入与撤销、图片上传、保存失败重试、并发保存、外部冲突、链接与恢复，以及长笔记编辑。
- 发布流程继续运行 Windows、macOS 构建、界面回归、Windows 安装升级矩阵和更新元数据校验。原生系统输入法及系统剪贴板仍需在实际桌面环境验收。
