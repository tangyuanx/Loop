# v0.2.10

本版本按知识笔记验证报告（KN-01～KN-39）集中修复编辑、文件安全与文档关系问题。

- 编辑：点击渲染代码块里的某一行，光标落在该行该字符处，不再把输入写到围栏之前。
- 编辑：单元格里的多行纯文本粘贴只写入本格；只有含制表符的表格数据才按网格覆盖，并且不再无提示改写相邻单元格。
- 编辑：新增行、清空行或移动列不再丢弃表头宽度之外的隐藏字段。
- 编辑：点单元格按点击字符定位；格内 Home/End、方向键与 ⌘B/⌘I 正常作用于该格。
- 编辑：重新应用任务列表保留已勾选状态；行内代码遇到内容里的反引号会自动加长围栏；外链标签里的方括号会被转义；“清除格式”支持一段选择内的多组混合标记。
- 表格：拖动列宽按手势所属的表格提交；表格控件可用 Tab 聚焦、回车进入单元格编辑；宽表格只在表格内横向滚动，“适应页宽”按真实视口计算，不再把整篇笔记撑宽。
- 文件安全：非法 UTF-8 文件不再被静默转码保存；只读文件不能通过目录项替换写入；原子保存保留原有文件权限；保存沿符号链接写入真实目标，链接本身保留。
- 文件安全：保存提交前再次核对磁盘版本，检出外部写入即中止并保留外部内容；“仍然覆盖”只作用于对话框里展示的版本，盘上再变会刷新并要求重新确认。
- 文件安全：只恢复本应用生成的替换备份，用户自留的 `.bak-*` 不会被移动到正式路径；Markdown 提交失败会回滚本次新建的附件。
- 文件：跨目录另存为会复制原笔记的相对附件；文件按原字节回到原路径后自动恢复“已保存”；附件缺失时不再显示缓存的旧图。
- 文档关系：文件名含 `%23` 的相对链接可正常打开；块锚点与标题锚点（大小写、Unicode 归一化）与嵌入使用同一规则；反向链接纳入可解析的相对 Markdown 链接。
- 文档关系：「⋯」菜单与空工作区新增“切换笔记…”，可按标题和正文搜索全部笔记，不再受“最近打开”条数限制；移除另一任务后保留的笔记不再白屏。
- 无障碍：阅读与编辑两种待办都带条目文字的可访问名称；重命名对话框关闭后焦点回到打开它的入口。
- 界面：任务详情浮层不再遮挡笔记工具栏；页面缩放时按可见宽度重排，查找/专注/更多入口仍可达。

导出说明：Markdown 导出保持原文（Loop 内图片内嵌，本地附件保留相对路径），导出面板会提示附件数量；HTML/PDF 继续内嵌本地图片。

已核验：根项目单元测试 376/376、知识专项 27/27、真实 Electron 桌面套件 15/15、Chromium 知识编辑器套件全绿，打包门禁四套（桌面/冲突/反馈/查找）全通过。已知未完成：正常退出瞬间新建笔记的持久化与存储阻塞时的退出提示（需故障注入环境复测）、附件文件热更新的 watcher。
