# Loop v0.1.241

本次精简右侧工作台与知识笔记的常驻控件，让正文与任务内容更突出，保留原有编辑、搜索、保存、文件及导出能力。

- 任务详情按需展开，笔记切换、阅读模式、搜索与更多操作集中在一行。
- 点击笔记正文不再出现外围边框；搜索沿用原有的按需展开形式及查找、替换能力。
- 格式工具改为窄长的纵向右键菜单，文本格式、段落设置、插入分别使用侧向子菜单；链接输入、图片上传及表格编辑继续使用原有能力。
- 底部合并重复保存提示；保存失败、只读保护及数据传输等重要状态仍优先显示。
- 原有双链、大纲、反向链接、笔记切换、文件关联、草稿恢复、冲突处理与多格式导出继续保留。

验证：347 项应用测试与 12 项服务测试通过；知识笔记编辑、搜索、导出、既有发布问题及新增工作台交互均完成真实 Electron 回归。发布流水线继续执行 macOS/Windows 原生打包、安装升级与打包应用验证，并核验更新文件和安装包后公开版本。

本版本基于用户已检阅的真实应用候选发布；检阅后仅调整版本元数据与发布文档，产品代码保持一致。
