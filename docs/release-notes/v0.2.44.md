## 数据保存与恢复

- 自动备份短暂读取快照时，笔记保存会等待并继续执行，避免误报恢复导入中的写入错误。

- 强化保存落盘、关闭前保存和损坏保护。遇到保存失败时保留当前内容并提示重试，损坏数据进入只读恢复入口。
- 工作区恢复增加校验、操作前备份和中断回滚，兼容旧版便携备份与升级备份。
- 新增包含任务、笔记和可移植附件的 `.loopbackup` 备份，可选密码加密。换机或防范设备故障时，请将备份保存到独立位置并妥善保管密码。
- 每天生成本机恢复点，默认最多保留 3 份、约 512 MiB 轮转，至少保留最近一份有效恢复点。手动备份和升级备份单独保留。

## 数据追溯与空间

- 记录任务、节点与笔记的实际变更，支持查看历史、恢复任务结论及节点内容的历史版本。
- 移除历史与最近删除记录的静默截断，保留追溯资料；旧版本未记录的历史无法补造。
- 图片按内容去重保存，避免草稿、历史与多次保存反复嵌入同一图片。业务历史与旧资源暂不自动清理。
- 设置显示数据用量和最近本机备份，并将数据概况、备份迁移、最近删除和整个工作区恢复分区展示，精简说明和提示。

本版使用新的工作区数据格式，旧版本将拒绝直接写入，避免降级覆盖。
