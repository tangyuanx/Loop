# Loop v0.2.17

本版改进处理流、速记和知识笔记的日常操作。

- 处理流行距更紧凑，节点与结论列可拖动调整。节点标题前的彩色按钮可单击循环切换状态，右键可直接选择。在「设置 → 任务与浮窗 → 处理流」可以管理自定义状态。点击节点外会清除选中底色。
- 速记为空时，浮窗在页签下只显示一条淡灰的添加提示。点击即可输入，缩小后的浮窗使用恢复图标。
- 知识笔记可用页签栏的「+」新建，按任务记住最近的保存目录。未保存时页签显示圆点，字数统计悬浮在正文底部。大纲与反向链接可以分别打开，正文展开显示。
- 图片可右键复制到系统剪贴板。节点标题、结论、记录和表格单元格用 Enter 保存退出，Shift+Enter 换行。链接只在点中文字时打开，光标位于链接内也可按 Ctrl+Enter 打开。
- 网页、Markdown、PDF 和只读代码可在 Loop 页签中打开。可在设置中改用系统应用，Office 等不支持内嵌预览的文件可交给系统应用打开。
