# Loop 0.1.252

完善软件更新流程，并在应用内展示本次升级包含的更新内容。

- 自动或手动检测到新版本后，点击“下载更新”才开始后台下载。
- 下载完成后停在“等待安装”状态，可继续使用 Loop；只有点击“安装并重启”才保存任务与笔记、生成升级前备份并开始安装。退出应用不会自动安装。
- 顶部更新入口与“设置 → 软件更新”显示当前版本到目标版本之间的发布说明，按版本从新到旧排列，最新版默认展开，较早版本折叠查看。
- 跨多个版本时限制说明阅读区域的高度；下载进度刷新保留展开状态、滚动位置和键盘焦点。
- 更新说明获取不全时提供提示和完整发布记录入口，不影响更新包的检查与下载。

本版本安装后，后续应用内升级采用以上流程。
