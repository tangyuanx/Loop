# Loop v0.2.15

修复知识笔记中表格编辑、附件另存为和阅读定位的问题。

- 表格适应页宽、自动列宽、精确设置列宽及复制后，保留当前单元格和文字选区。自动列宽恢复内容布局，调整一列时保留其他列的显示宽度，适应页宽按实际可用空间计算。
- 单元格内加粗、斜体、删除线、高亮和行内代码可再次取消，保留文字选区，支持独立撤销重做。进入空白表格行时保持原有高度。
- 附件另存为遇到内容不同的同名文件时提示冲突，保留原文件。保存失败只回滚本次创建的附件，并拒绝通过符号链接复制笔记目录外的文件。
- Setext 标题支持锚点跳转。切换阅读模式时避免使用已失效的文档位置。复制代码去除围栏所需的结构换行，并保留主动空行。
