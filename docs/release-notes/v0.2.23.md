# Loop v0.2.23

## 笔记左右分屏

- 两篇笔记可左右并排编辑，各自保留撤销、滚动、查找和视图模式。右键点击页签可在左侧或右侧打开，也可从正文右上角「⋯」进入分屏或合并单栏。
- 拖动中间分隔线调整宽度，或聚焦后用左右方向键微调；双击恢复等宽。
- 专注只放大当前栏，退出后恢复双栏与原宽度；切换应用全屏时保留当前布局。
- 两栏继续使用各自原文件，保存、外部更新和改名互不串栏；关闭页签不删除文件。

## 创建与今日浮窗

- 新建任务弹窗统一字号与行高，保留草稿、选项滚动位置和取消后的键盘焦点。
- 扩大今日浮窗的空白拖动区域，修复连续调整上下边缘时的跳动，以及后台刷新打断拖动区域的问题。
- 修复同一笔记的标题和别名重复时，反向链接被误判为名称歧义的问题。
