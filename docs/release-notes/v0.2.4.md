# Loop 0.2.4

整理桌面工作台的配色、顶栏与任务属性展示，保留处理流和笔记的原有操作。

- 明暗主题采用更清晰的中性色阶，区分导航、任务列表、正文、选中与悬停状态；输入焦点继续使用中性细线。
- 左栏与顶栏融为同一底色，任务列表与正文通过连续的圆角边界分隔，列表默认宽度收紧到 240。
- 更新入口放在左下角设置右侧，两栏折叠按钮分别与对应栏对齐；移除右上角重复的设置和完成任务入口，列表原有完成操作保留。
- 顶部路径只显示分组与任务名称，路径不再触发分组修改。点击任务名可原位编辑，编辑和取消时保持位置稳定。
- 标签、优先级、时间与分组等属性放入右上角浮动卡片，收起后显示信息图标，不占用正文宽度；默认展开会遮挡节点工具时自动收起。
- 背景、进展与结论保留在主内容区，继续自动保存。精简设置中的重复说明，保留现有选项。

保留处理节点的父子关系、折叠与拖动，以及记录浮窗的缩放、位置恢复、保存和撤销行为。
