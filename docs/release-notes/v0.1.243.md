# Loop v0.1.243

本次修复知识笔记编辑与阅读模式的换行呈现差异。

- 阅读模式保留原文中的单次回车，逐行文字不再被合并成一行。
- 原本独占一行的图片与前后文字保持分行；同一源行中的图片和文字继续同行。
- 嵌入笔记、HTML 与 PDF 导出使用一致的换行规则。
- 不改写原始 Markdown，保留原有换行格式、图片引用与保存逻辑。

验证：347 项应用测试、12 项服务测试及完整编辑器回归通过；新增真实 Electron 用例覆盖明暗主题、两种窗口宽度、独立/同行图片、LF/CRLF/CR、硬换行、列表、引用、表格、代码、嵌入及三格式导出。发布流水线继续验证 macOS/Windows 打包应用、Windows 安装升级与完整发布文件。
