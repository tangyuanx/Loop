# v0.1.234

## 知识笔记工作区优化

- 精简常用格式工具栏，将表格、代码块、图片及低频格式统一收进“插入”菜单，移除重复图片入口。
- 页宽设置移至底部，保留默认、较宽、全宽三档；减少正文两侧空白，让编辑、源码与阅读模式使用一致的正文区域。
- 简化笔记标题栏和保存状态，弱化手动保存按钮，保留文件路径与状态提示、保存失败重试及冲突处理。
- 实时预览使用圆点呈现无序列表，任务列表移除重复的 Markdown 符号；折叠入口按需显现，已折叠内容仍有展开入口。
- 大纲标出光标所在章节，保留反向链接，并优化窄窗口和深色模式的排版。
- 查找替换面板中文化；“插入”菜单支持方向键、Enter 和 Escape，操作保留正文选区与撤销历史。
- 包含上一版发布后合入的软件更新设置精简：只展示一组当前版本与可用版本对照，并保留下载进度与升级操作。

## 验证

- 本地主项目 325 项测试与反馈服务 11 项测试通过。
- Chromium 界面回归覆盖菜单键盘操作、页宽、大纲、浅色/深色与窄窗口，以及中文输入、Markdown 原文、换行格式、模式切换、撤销、保存竞态、冲突及恢复。
- 发布流程验证 Windows、macOS 构建、Windows 安装升级矩阵及完整跨平台更新文件。原生输入法和系统剪贴板的最终体验仍以实际桌面环境为准。
