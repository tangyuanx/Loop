# Loop v0.1.228

- 默认中文黑体使用内置 Noto Sans CJK SC 轮廓字体，降低不同设备上的字体替换差异，其他中文字体选项与 Times New Roman 设置保留。
- 导航、任务标题、处理流、设置及浮窗等界面文字使用常规字重，主要字号按整数 CSS 像素呈现。
- 为任务标题、导航及相关控件增加上下绘制空间，修正处理记录输入框的字号与行距，减少文字被裁切的风险。
- Windows 启动时统一关闭 LCD 子像素文字渲染，使用灰阶抗锯齿策略；保留系统 DPI 缩放及硬件加速设置。
- 主窗口、今日浮窗与浮窗面板共用同一套字体修正。

验证：`npm run check`（309 项桌面/模型测试、11 项服务测试）；真实 Electron 中的四档字号绘制空间、节点改名和已完成筛选检查；`git diff --check`。本地真实截图来自 Linux，Windows 的最终字体观感仍需实机检查。发布流程执行 Windows/macOS 界面回归、构建、Windows 安装器升级和更新文件校验。
