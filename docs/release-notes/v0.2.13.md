# Loop v0.2.13

这版改善了主窗口和浮窗的切换稳定性。处理流、知识笔记和历史处理共用同一排页签，仍在任务简报下方。

- 三个视图来回切换时，页签和正文起点保持原位。侧栏和任务列表收起后，可在同一位置点开。
- 任务详情展开时给笔记的查找、专注和「⋯」留出空间。笔记大纲的关闭按钮也可直接点击。
- 固定筛选按钮和搜索框的位置。选择定位结果后自动关闭定位弹层，节点记录可以立即操作。
- 「工作与成长」弹窗切换页签时保持外框位置。默认右上角的今日浮窗收展时，顶栏按钮保持对齐。

macOS 已验证快速反向切换、窗口缩放、实际双屏往返及原生指针跟随。Windows 实机操作留待后续，步骤见 [Windows 切换稳定性验证](https://github.com/tangyuanx/Loop/blob/v0.2.13/docs/testing/windows-switch-validation.md)。
