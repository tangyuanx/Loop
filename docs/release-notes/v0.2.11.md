# v0.2.11

知识笔记采用单层浏览器式页签，标题、切换和新建集中在同一处。

- 双击页签即可重命名笔记，也可聚焦页签后按 F2。关闭重命名窗口后，焦点回到对应页签。
- 页签等宽显示，长标题以省略号展示，悬停可查看完整名称和文件路径。
- 页签随可用空间等宽收缩。缩至只容纳关闭按钮后，显示左右滚动按钮，并支持鼠标滚轮与横向滚动。
- 顶部、页签区和正文使用统一底色，标题与关闭按钮共享页签表面，键盘焦点保留中性细线反馈。
- 任务切换和界面重绘保留页签滚动位置，窗口变窄时当前页签保持可见。单篇笔记也显示页签，关闭最后一篇后可通过「＋」新建。

本地已通过页签交互、文件保存与重启、冲突处理、查找和明暗主题输入焦点验证。发布流水线继续执行双平台实际包、Windows 升级和更新文件完整性检查。
