# Loop 0.1.250

知识笔记采用更自然的文件工作流程，并完善普通表格操作。

- 笔记不再强制绑定任务，也不区分创建来源。任务切换和应用重启时恢复上次使用的笔记；多篇显示页签，单篇保持简洁。
- 新建直接进入空白编辑，首次保存时选择本地位置。打开直接选择 Markdown 文件，最近记录可快速重开文件和未保存草稿。
- 完善表格行列增删、复制、清空、排序、对齐、列宽调整和粘贴，支持拖动与键盘操作，并保留撤销历史。
- 修复空表格显示、单元格文字重叠与换行、重启后编辑器停留加载状态，以及关闭页签后意外重新打开的问题。
- 去除笔记正文聚焦时的异常横线，保留清晰的中性编辑光标和现有界面风格。

已有笔记、文件关联与可恢复草稿继续保留。开发候选已通过真实 Electron 文件流程、表格、编辑、保存异常和明暗主题检查；发布同时执行实际安装包回归与更新文件摘要校验。
