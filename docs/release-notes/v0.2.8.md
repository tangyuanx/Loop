# v0.2.8

- 知识笔记：修复点击渲染块（代码块、表格、提示框、分隔线）下方或图片附近的行时光标落到下一行的问题；编辑模式不再在每个渲染块上下多出空行。

- 输入控件（搜索、查找、标题改名、表格单元格、设置等）在明暗主题下都不再出现绿色边框、外框或光晕，键盘焦点保留中性细线。
- 笔记查找在阅读模式下读取真实选区；格式化菜单不再在无编辑器时打开。

已核验：知识笔记单元测试 27/27、真实 Electron 桌面套件 15/15、Chromium 知识编辑器套件全绿（含表格、导出、保存与冲突路径）。新增块控件按下半部点击、滚动后点击、表格行列保存重开、输入焦点四组使用性回归，并在回退修复的构建上确认前两组会真实失败。Windows 与真实数据试用仍待验证。
