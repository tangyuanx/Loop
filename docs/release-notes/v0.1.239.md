# v0.1.239

- 知识笔记查找改为右上角紧凑面板：默认隐藏，点击搜索按钮或按 Ctrl/Cmd+F 后展开，Esc 或关闭按钮收起。
- 匹配内容直接在正文高亮，支持匹配计数、上下处跳转、大小写、全词、正则及按需展开替换；保留撤销历史。
- 明确区分“切换笔记”和“查找当前笔记”，支持实时预览、源码、阅读与表格中的可见文本高亮。
- 优化发布流程：主分支仅做检查，标签只运行一套跨平台发布构建；缓存 Electron、打包工具和历史升级安装包。
- 安装包在各平台通过完整检查、安装升级及包内回归后直接上传草稿版本；统一核对两平台清单、更新源与服务端文件摘要后才正式发布，减少大文件中转。

发布保留全量应用/服务检查、Windows 三个历史版本升级测试，以及两平台导出、冲突、保存反馈和搜索共35组包内回归。
