# Loop v0.1.240

本次修复知识笔记发布前测试发现的 14 项问题，改善连续编辑、草稿关闭、表格输入、文件状态和导出体验。

- 草稿处理对话框现在可见、支持键盘操作与取消；“保存”会选择本地文件，删除任务时能正确进入后续确认。
- 工具栏及标题下拉操作后可直接继续输入，撤销正常；插入代码块和表格后光标进入内容位置。
- 整行格式化保留标题、引用和列表语法；列表转换不再额外生成空项。
- 表格内粘贴电子表格内容按行列填充，支持扩展行列与撤销。
- 只读保存失败不再重复显示“重试”，重新加载文件后清除旧失败回执。
- Markdown 导出内嵌 Loop 图片引用，改善分享时的图片可用性。
- 笔记切换列表移除内部标识，完善暗色高亮、笔记链接样式及键盘焦点。

验证：347 项项目测试与 12 项服务测试通过；13 个真实 Electron 场景覆盖全部 14 项问题，源码与本地 macOS 打包应用均通过。另通过既有冲突、保存反馈和搜索回归。发布流水线继续执行 macOS/Windows 原生打包、安装升级与打包应用验证。
