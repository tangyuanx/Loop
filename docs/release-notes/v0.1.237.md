# v0.1.237：完成知识笔记冲突处理与保存反馈修复

- 冲突处理成功后关闭对应弹窗；取消或失败保留草稿、Recovery 与操作入口，显示失败原因并支持重试。较晚返回的操作不会关闭另一篇笔记或新打开的弹窗。

- 空白笔记名称显示“请输入笔记名称”，保留输入焦点并提供无障碍错误标记；支持中文组合输入，阻止重复提交，保存失败可重试。
- 保存回执、快捷键提示和文件菜单统一区分“保存到 Loop”与“同步到文件”；绑定、解除关联、切换笔记、保存失败及冲突时及时更新。本地落盘后不再残留进行中的提示。
- 保留 v0.1.236 的公式、图表、离线 HTML/PDF 导出与图片光标修复，并完成最终回归。

发布流程新增 macOS、Windows 打包应用回归门禁：导出、冲突、名称及保存反馈测试全部通过后才上传正式安装包。
