# Loop 默认示范任务方案

**示例：排查搜索结果为什么跳回旧查询**是一个前端异步排障案例。先输入 `ap`，再输入 `app`，列表先显示 Apple，随后又出现 Apricot。用户接手查到一半的处理流，用请求日志定位错误写入、补回归测试，再把这次学到的方法留在知识笔记。案例使用虚构应用和本地样本。

功能基线取远程最新标签和 `main`，两者均指向 v0.2.85 的 `5a6a432b73b778e5dea0c5f2d6e9b106444b365e`。[v0.2.85 源码](https://github.com/tangyuanx/Loop/tree/v0.2.85)

## 打开示范任务

在 Loop 的「任务仓库」列表顶部点击「⋯ → 导入任务包…」，选择 [loop-onboarding.looptask](./loop-onboarding.looptask)，点击「导入为新任务」，然后点「打开任务」。切换到「知识笔记 → 排查路线」开始。已有工作区可以选一个专门的练习分组。

| 内容 | 初始状态 |
| --- | --- |
| 主任务 | 进行中、中优先级，背景有复现步骤和预期结果，进展保留已有证据，最终结论留给用户 |
| 处理流 | 4 个根节点、共 20 个节点，最深 3 层。9 个已完成、2 个待确认、9 个未完成 |
| 节点关联 | 「先发的请求晚到后覆盖了结果？」关联「修复并补回归测试」，可分享根因和相应验证 |
| 知识笔记 | 「排查路线」「排查证据」「排查复盘」「功能练习」四篇草稿，附章节跳转 |
| 附件 | 请求时序图、故障快照 PDF、请求事件与回归预期 JSON |

## 问题解决过程

1. **并行验证假设。** 缓存键混用、防抖漏发和异步响应乱序是三个同级分支。前两条已有排除依据，响应乱序仍需核对。
2. **证据带出新分支。** 后发的 B 请求先返回，先发的 A 请求在 450 ms 写回旧结果。修复后分别验证乱序成功、清空时请求仍在途、旧请求迟到失败，以及新输入仍在等待防抖时的情况。
3. **把独立问题交接出去。** 调查还发现搜索无匹配时缺少提示。用户可将它记成速记，再转为跟进任务，让原来的异步问题先闭环。
4. **留下可复用的经验。** 任务简报记录本次根因和结果。知识笔记沉淀可控异步测试的做法。历史处理保留从最初猜测到确认的过程。

## 首次启动预置方案

当前原型使用手动导入入口。以下规则用于接入首次初始化。

- 新建工作区且首次初始化完成后，预置一项示范任务并选中它。保留已有工作区、升级、迁移和备份恢复中的数据和界面选择。
- 初始化时由现有的持久化事务保存任务、节点、笔记、资源和一次性初始化记录。关掉应用或删除示范任务后，重启仍尊重这次选择。恢复工作区时沿用备份本身的内容。
- 以普通任务呈现，用户可改名、完成、删除、恢复或分享。想重新开始时，用同一份任务包导入独立副本。
- 初始状态不设置截止时间、循环、系统提醒、今日标记、全局自定义状态或文件关联。日期练习统一使用操作当天及其前后日期，笔记在 Loop 内以草稿打开。进阶设置由用户在练习中启用。
- 在「排查路线」开头留一个可直接验证的待确认节点。「功能练习」提供进阶入口，用户可以先完成问题排查。历史来自真实保存、状态变更和恢复，可复盘每一步的结果。

## 功能覆盖与完成标准

| 功能面 | 用户操作与可观察结果 |
| --- | --- |
| 任务新建与简报 | 从仓库新建搜索空态跟进，原位改名，填写背景／进展／结论。练习保存、换行和取消，折叠后展开能继续编辑，简报计数跟随已填项 |
| 任务仓库与分组 | 新建、改名、调整分组顺序，移动任务到分组或未分组，排序同组任务，复制任务摘要。删除临时分组时分别核对保留内容与一起归档的范围 |
| 任务标签与时间 | 切换优先级、加入或移出今日、标记稍后和卡住，观察任务列表元信息。体验仅日期、具体时刻、提前提醒、关闭提醒、每天及每周多选循环，看本次完成与下一周期到期 |
| 搜索、筛选和批量 | 搜索任务、节点和速记，从结果回到对应详情。组合筛选类型、状态与优先级。进入「多选」，试全选、分组、截止时间、优先级、今日、完成检查、恢复与删除 |
| 今日与桌面浮窗 | 观察手动加入、今日截止、循环到期三种进今日的方式。练习任务与速记页签、编辑、排序、转换、打开主窗口、显示／收起、拖移、缩放、透明度、置顶和穿透 |
| 处理流结构 | 从已有三层假设树新增根、子和同级节点，把复现中的新发现拖到合适的回归分支。展开／收起一支或全部，核对折叠分支的完成数。通过定位与层级面包屑跳转，路径出现时切换右侧三个页签 |
| 节点状态与证据 | 区分已用证据排除、仍待确认和未开始的检查。管理并应用临时自定义状态，试「仅待确认」「隐藏已完成」。原位改标题和 Markdown 结论，在记录窗编辑验证过程，核对保存后再打开的结果 |
| 任务闭环 | 先触发缺结论和未完成节点的检查，再补齐根因、修复和验证结果。观察仓库、今日已完成与回顾，重新打开普通任务，再单独体验循环任务完成本次 |
| 日历 | 设定当天、未来、逾期的练习任务。翻月、回到今天、选日，核对日格预览条与逾期角标。打开当天任务或将日期带回任务仓库，再清除 |
| 回顾 | 用本周、本月、今年、全部和自定义，切换创建、更新、解决日期。观察闭环、已完成节点、结论和卡住四项统计，以及近 13 周节点活动 |
| 笔记页签与归属 | 新建、打开和最近打开，切换、重排、溢出滚动、改名、关闭后重开。用三篇笔记左右分屏、调整宽度、换另一栏和合并。在第二项任务练习归属与参考，核对默认分享选择 |
| 笔记编辑与导航 | 切换编辑、源码、阅读、专注和页宽。练习标题、列表、引用、任务框、行内格式、代码、公式、图片、链接、文档格式化和属性；用大纲、反向链接和标题锚点往返。试查找的大小写、全词、正则、替换与撤销 |
| 表格与资源 | 练习文字和单元格选区、复制粘贴、合并与拆分、行列增删移动、清空、对齐、适应页宽、自动列宽及精确调整。试图片缩放、对齐、复制，以及 PDF、JSON、网页的内嵌或系统打开 |
| 笔记文件与导出 | 在练习目录保存、另存、打开、改名并更新相对链接，查看文件信息。用临时文件体验外部修改、缺失、重新定位、重新加载、覆盖和解除关联。预览并导出 Markdown、HTML、PDF |
| 节点与任务分享 | 比较节点子树深度与下游关联层数。比较任务分享各预设、自定义选取、记录、笔记、附件补选或排除。导出 Markdown、PDF 与任务包，预览后导入新任务，检查原记录、笔记和附件 |
| 历史处理 | 修改节点结论、记录或笔记正文后查看保存事件，比较前后版本，恢复其中一版并核对恢复记录。累计多次编辑时可加载更早记录 |
| 最近删除 | 对练习任务、速记、分组、节点和笔记分别体验撤销、搜索、按类型筛选和单项／多项恢复。观察缺失父级、原分组和重名的恢复提示。在设置查看保留期及过期清理预览 |
| 数据与升级恢复 | 查看本机空间和自动恢复点，导出普通与加密工作区备份。用隔离工作区体验备份文件、备份目录、最近备份和可用的升级前副本恢复，以及缺失、损坏、超版本的只读保护 |
| 工作与成长 | 配置工作日、时段、学习来源、通知和自动推进。试纯文本／JSON 导入、去重预览、队列继续与暂停、卡住后切换、完成推进、来源更换及时间预览 |
| 外观、偏好与帮助 | 切换明暗主题、窗口布局、中英文字体、字号、界面切换偏好并恢复默认。应用任务、浮窗及笔记全局偏好，查看手册目录并搜索。查看更新状态和反馈表单，反馈练习以取消结束 |

闭环、回顾和恢复可直接使用预置任务。涉及两条及以上记录的操作由用户现场新建跟进任务或速记。系统通知、工作区替换、更新安装和外部文件异常各自要求相应的系统条件或隔离环境。

## 原型验证

四组事件样本分别有预期界面状态，可按事件顺序重放核对。在 macOS 的隔离资料目录启动 v0.2.85，核对任务包预览与导入、处理流 9/20 进度、下游关联分享、跨笔记章节跳转、四篇笔记和三个附件入库、证据图显示、笔记查找与历史处理页签。
