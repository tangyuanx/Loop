## 保存和恢复

- 任务保存采用独占临时文件、文件同步、同目录替换和可用平台上的目录同步。已有工作区标记可区分首次启动和主文件丢失。
- 主文件语法或结构损坏、图片缺失或摘要不匹配、未来数据版本、恢复草稿损坏时进入只读保护。原始字节保留。恢复入口可以直接选择备份，无需先保存损坏工作区。
- 退出会等待任务、节点编辑和恢复草稿。写入失败或等待超时会暂停退出并保留编辑现场。退出请求带身份编号，迟到的确认无法结束后续请求。节点编辑的待保存状态立即可见。
- 导入先在同卷暂存并校验完整候选，保留安全副本，再逐项切换。持久化恢复日志覆盖准备、移出原数据、激活、回滚与清理。中断后启动可回到完整旧版本或确认完整新版本。恢复来源不明、待恢复日志无法证明或版本过高时保持保护。
- 已初始化的当前工作区会阻止历史目录自动替换。多个旧工作区或备份需要选择具体目录。镜像同名冲突仅清理本次新建材料。
- 显式指定 profile 的候选把导入前副本保存在自身目录，验收过程的备份和数据可随该 profile 一起处理。

## 日常空间和历史

- 新存储格式为任务数据 v4。内嵌图片迁移到 image-assets/ 下按 SHA-256 命名的二进制文件。任务、恢复草稿、节点、归档和历史可共用同一份内容，读取接口仍向现有编辑器提供可用的原始内容。
- 图片落盘并校验后才提交引用。缺失或变动的旧图片会阻止继续写入。旧版应用按数据版本保护停止覆盖 v4 工作区。
- 正式 Markdown 及其自包含附件继续位于所选目录。迁移以保留可恢复材料为先，旧附件暂存和历史副本的回收需要完整引用核验，当前没有自动删除这些业务材料。
- 后端记录任务、节点和笔记的实际变更时间、稳定身份、状态、位置与内容版本。与对应业务状态在同一次任务库提交中落盘。连续文本输入按编辑会话合并，读取历史分页，偏好或视图切换不会产生业务历史。
- 任务结论和节点记录、结论可以恢复历史版本，恢复本身再记录一个新版本。已有旧版摘要保留，迁移前没有保存的版本无法补造。
- 最近删除超过 500 项后继续保留。历史和最近删除会随实际业务记录增长，当前没有静默裁掉旧记录的容量上限。

容量复测使用一张实际为 1,045,108 字节的合成 PNG，调用真实存储函数。旧格式的草稿阶段占约 3.66 MiB，正式保存后占约 3.32 MiB。新格式的草稿阶段只有一份 1,045,108 字节的图片、334 字节主库增量和 514 字节恢复记录。正式保存后，应用内仍是一份图片，主库增量 457 字节；笔记目录额外保有一份 1,045,108 字节正式附件。连续修改和保存标题 50 次未生成历史整库副本或额外图片文件。文件逻辑大小与文件系统物理分配大小分别对待。

## 备份和数据保护

- 新 .loopbackup 格式采用流式 ZIP 和逐文件摘要校验。包含任务、业务历史、草稿、托管资源、用户确认范围内的绑定 Markdown 和可移植相对附件。缺失文档、排除项与不可迁移资源数量在结果中显示。
- 恢复到新位置时，在 workspace-notes/ 中重建文件并重新绑定。去掉来源设备的保存目录偏好，保留缓存正文和脏文件冲突依据。缺失正式笔记的缓存正文可作为草稿恢复。
- 可选密码备份使用 scrypt 派生密钥和 AES-256-GCM，头部和密文均认证。密码不保存。错误密码、密文损坏与普通文件摘要不符均在切换当前数据前失败。
- 导入限制路径、文件类型、条目数量、单文件和总容量，拒绝跨平台保留名、大小写或规范化冲突、符号链接越界及目录穿越。密码备份的明文暂存位于私有的应用暂存目录，启动时清理本次操作所属的中断材料。
- 保持旧版 JSON 便携备份和目录备份可读。目录带清单时验证原清单；旧版无清单目录标注来源。macOS 外置盘产生的 AppleDouble/Finder 元数据不会阻断备份校验，旧备份清单中已有这些元数据时也能读取。
- 本机自动恢复点按本地日历每天生成一次，15 分钟检查，启动后首次检查约 10 秒。默认最多三份、约 512 MiB 轮转，只在新恢复点验证后处理自有旧恢复点，至少保留最近有效的一份。单份超过预算时仍保留。手动导出和升级副本单独保留。
- 自动恢复点保留外部文件绑定和应用内正文，适用于本机恢复。换机或设备故障需要保存在独立位置的工作区备份。外部源目录里的文件、安装包和下载包的占用需在各自位置核对。
- 设置显示主库、托管内容、备份用量、最近有效本机备份时间及错误状态，支持直接恢复最近本机备份。输入及祖先容器在明暗主题的焦点验证中保持中性边界。
