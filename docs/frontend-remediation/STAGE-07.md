# 执行阶段7：今日浮窗与独立辅助窗口

先读`COMMON.md`、共享状态/决策、`handoffs/STAGE-06.md`和路线图阶段7，运行`node tools/frontend-remediation.cjs check 7`。阶段1应已接入基础输入规则，本阶段落实完整独立窗口体验。

## 目标

将今日任务、速记和真实跨窗口操作带入同一视觉系统，保留窗口和草稿可靠性。

## 必须完成

1. 整理任务/速记、改名、快速输入、完成、排序、移动、升级与删除；原位输入不新增第三层底色。
2. 整理浮窗设置、行菜单、速记升级与删除确认，继续使用真实独立BrowserWindow，避免裁切与错误位置。
3. 核对主窗口→浮窗→辅助窗口的主题、字重、字体/字号、状态和数据快照传播；不只在主窗口检查CSS。
4. 验证置顶、穿透、透明度、拖动/缩放/吸附、关闭/重开与主窗口唤起。标题栏原生能力、阴影透明区和点击区域保持正确。
5. 主窗隐藏/关闭/后台、窗口失焦和快照刷新时保留输入草稿；相同请求只修改一次主数据。

## 代码重点

`today-widget.html`、`widget-surface.html`、两个runtime、`widget12.css`/`widget13.css`/`widget-bridge.css`/`widget-surface.css`、`app/main/today-widget.cjs`及已有preload契约。

## 验收与交接

- 两种主题及真实多窗口、边缘/跨屏/DPI、主窗前后台、输入/改名/排序/菜单/重开；浏览器内模拟浮层不是这项验收。
- 参考`today-widget-draft.ui.cjs`、`context-create.ui.cjs`和浮窗/消息/偏好回归，完整检查与空白检查。
- 跨平台或多屏无法实测的项登记给阶段8，不能冒报通过。
- 启动真实独立窗口供审阅，写`handoffs/STAGE-07.md`与状态/决策，不提交或发布。
