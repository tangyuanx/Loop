# 知识笔记发布前测试报告：核实、分阶段修复与验收

日期：2026-10-24（Asia/Shanghai）。原报告测试 0.1.238 / 3760164；本次基于远程最新 0.1.239 / b94e539，在独立工作区准备 0.1.240 本地候选。原工作目录的未提交改动完整保留。

## 判断与修复

14 项均有问题依据。D2 的实际根因比原报告更具体：编辑器本身已恢复焦点，但动作分发紧接着无条件 render，重新挂载工作区再次丢焦。D12 属于输入安全边界缺陷，即使没有承诺电子表格能力，也不应把 TSV 原样插入一个单元格而破坏表格。

| 阶段 | 编号 | 已核实的问题及处理 |
| --- | --- | --- |
| 一：阻断 | D1 | 弹窗确实无定位样式。增加固定遮罩、居中和限高滚动、焦点圈定、Esc/取消及焦点返回；关闭菜单后再开弹窗。覆盖关闭草稿与删除任务两条路径。额外修正“保存”调用 Save As，让文案与行为相符；原来只保存到 Loop。删除草稿后移交最近删除确认时先释放旧弹窗。 |
| 一：阻断 | D2 | 格式命令后不再执行整页刷新；撤销/重做恢复编辑器焦点；标题自定义下拉不再覆盖命令恢复的焦点。格式修改和随后输入隔离撤销历史，能够逐步撤销。 |
| 二：编辑/内容 | D3 | 代码块插入后光标放入围栏中的空行。 |
| 二：编辑/内容 | D4 | 表格插入后将源码光标放在首个数据单元格；实时预览等待表格完成解析/布局后打开单元格输入，Tab 移至下一格。等待有次数上限，期间用户改文档或移动光标则放弃接管。 |
| 二：编辑/内容 | D5 | 行内加粗/斜体/行内代码等保留标题、引用和列表前缀；跨行逐行处理并保留空行。 |
| 二：保存状态 | D6 | 已有文件状态提示能提供恢复操作时，不重复显示通用保存错误和第二个“重试”。 |
| 三：界面 | D7 | 切换器/歧义列表/补全详情改为分组、任务、文件名或草稿位置及更新时间，去掉内部 noteId。 |
| 二：编辑/内容 | D8 | 批量列表格式化排除选区末尾空白行；保留原有换行，不生成空列表项。 |
| 二：保存状态 | D9 | 重载成功时清理旧保存失败回执；读取失败或取消时仍保留错误与草稿。 |
| 三：界面 | D10 | 暗色和浅色主题都给高亮提供可见背景，文字继承正文色。 |
| 三：界面 | D11 | 确认 controls22 的高优先级样式覆盖了焦点轮廓；给段落下拉恢复可见的键盘焦点轮廓。 |
| 二：编辑/内容 | D12 | 表格单元格内 TSV/多行粘贴按网格填充，必要时扩展行列，保留分隔行并转义竖线，整体可撤销。 |
| 二：导出 | D13 | Markdown 导出的 task-image 目标改为快照图片的 data URL；原编辑内容和文件关联保持。缺失图片阻止导出并提示，不交付静默破损的引用。普通 Markdown 导出保留原有字节。 |
| 三：界面 | D14 | 阅读中的笔记链接使用主题链接色、下划线和键盘焦点轮廓。 |
