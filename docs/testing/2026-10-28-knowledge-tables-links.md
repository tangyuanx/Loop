# 知识笔记：表格与多文档关联

后续用户截图证实本轮功能断言未覆盖非空表头的实际叠字和键盘落点。本报告应结合后续[真实运行复查](2026-10-28-knowledge-table-native-review.md)阅读；后者包含实际复现、修复与原生截图，不把测试数量当作视觉正确性的证明。

本地候选基于 `64ee45b`（0.1.249），未升应用版本、提交或发布。沿用生产工作台、CodeMirror 编辑器、文件 IPC、恢复与冲突处理，不使用独立 Demo。

## 修复与补齐

- 表格空行稳定为 42px，输入框限制在单元格内；明暗主题焦点均为中性底线，未使用绿色边框或光晕。
- 表格下方可直接添加行、添加列、打开行列设置；设置可选择行列，向上下插行、向左右插列、删除正文行/列/整表、更新单元格、设置对齐与列宽。
- 保护表头和最后一列，允许删除最后一行正文；Tab/Shift+Tab 切换单元格，末格 Tab 续行，Enter 纵向切换，Escape 退出。支持电子表格 TSV 粘贴、扩展行列、管道符转义、撤销/重做、中文组合输入、三种视图与保存恢复。
- 多张表的操作定位到对应表格，不受其他表格正在编辑的单元格影响。
- 新笔记保存在独立 `knowledgeDocuments` 集合，任务只记录关联和当前打开项。旧 `task.notes/knowledgeNote` 保留兼容，旧数据不丢失。
- 任务内标签区分“本任务创建”和“其他笔记”；新建不新建任务，打开其他笔记不切换任务，关闭标签仅移除关联。各笔记独立保存、重命名、绑定文件、导出和恢复。
- 打开 Markdown 文件新增/复用独立笔记，不替换当前正文；同一路径不重复创建笔记。
- 删除创建任务时保留笔记；恢复任务时合并现存最新笔记，稳定身份不变。主进程文件授权、最近删除事务回滚和浏览器存储均覆盖独立笔记。
- 知识数据结构版本升至 2，旧版应用会按既有保护机制拒绝覆盖新版数据库，避免丢失独立笔记。
