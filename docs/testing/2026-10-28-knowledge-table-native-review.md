# 表格真实运行复查

用户再次提供截图后，上一轮“功能通过”的结论不能覆盖实际编辑画面。本轮以真实 Electron 窗口中的操作和原生截图为主要证据，保留原有工作台设计与累计修改，未发布。

## 实际复现与修复

1. **非空表头双层文字**：真实点击“项目”即可复现原文与输入文字同时显示。原位编辑背景必须透明，原渲染文字却未停止绘制；同时全局普通输入规则把表头编辑字重改为400、对齐改为左侧，原表头为600/居中。
   - 编辑时只绘制编辑字段，隐藏的内容负责行高；退出后恢复实际渲染。
   - 编辑字段继承单元格字体、字重、行高、对齐和内边距，保留透明背景、中性底线。
   - 使用可自动换行的原生文本区，长中文在输入过程中完整显示；不加第三层输入背景掩盖问题。
2. **末格 Tab 续行错列**：在真实窗口连续输入时，新行光标落在最后一列，下一次 Tab 又产生一行。现改为新行第一列，连续输入落点正确。
3. **窄窗口下一格被遮住**：实际拖动原生窗口至1024×680、深色/特大字号下，长内容把下一行推到窗口下方；键盘虽然切换单元格，光标被底栏遮住。现对键盘导航及插入后的目标单元格做邻近滚动，真实复测可见完整目标单元格。
4. 没有活动单元格时，表格下方“添加行/列”追加到末尾；有活动单元格时保留在其下方/右侧插入的含义。多张表操作仍按各自表格定位。

## 本轮真实操作

使用 CUA 原生鼠标、键盘与系统剪贴板操作正在运行的正式源码应用，逐次读取实际界面和截图：

- 非空表头进入编辑、替换文字、退出；中文长内容、两行表头、加粗 Markdown、中英数字与 emoji 混排。
- Tab/Shift+Tab、末格续行、连续输入；单元格中撤销/重做；窄窗口跨行后滚动与光标可见性。
- 系统剪贴板粘贴二维 TSV（含竖线），跨行分配并转义；两张表追加列、删除列、最后正文行删除与撤销、表头删除保护、居中对齐。

- 同任务独立笔记编辑保存、打开其他任务笔记而保留当前任务、关闭关联后从笔记列表重新打开。
- 完整退出并重新启动多次，真实输入内容与关联均保留。

其余表格操作（上下插行、左右插列、列宽、删除整表、边界保护）由真实 Electron 的按钮交互套件完整回归；保存/文件选择/授权经过完整进程重启验证。
