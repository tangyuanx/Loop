# 任务笔记页签隔离 · 2026-10-29

用户指出上一候选仅清空了新任务正文，但仍显示旧任务笔记页签。本次将“打开的页签列表”与“当前笔记”一并按任务保存，替代此前全局共用页签的实现。

## 行为

- 新任务首次进入笔记只创建一篇独立空白草稿，当前任务只打开这一篇，隐藏页签栏。
- 切换任务时保存离开任务的页签与当前项，恢复目标任务自己的页签与上次使用笔记。
- 在当前任务主动新建或打开多篇笔记才显示页签栏；同一篇独立文档仍可由不同任务主动打开，内容共享、页签状态各自独立。
- 最近记录继续全局可用；从旧版全局页签迁移时，各任务保留自己的上次笔记，其他旧页签仍在最近记录中，不删除文档或草稿。
- 首次保存、文件路径授权、草稿恢复、关闭全部页签后的空状态沿用原机制，界面样式未改变。

使用现有 `knowledgeWorkspace` 存储中的 `tabsByTask` 保存每个任务的打开列表；`openIds` 保留为当前任务列表，现有渲染与编辑器复用机制继续使用它。共享 normalizer 同时覆盖桌面与浏览器存储。异步打开文件在用户已切换任务时只更新原任务的页签，不插入当前任务列表。
